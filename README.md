# 🍔 Food Order Website

A responsive and user-friendly food ordering website built with HTML, CSS, JavaScript, Bootstrap, PHP, and MySQL for seamless online ordering.

## 🚀 Features
- Browse food menu
- Add to cart functionality
- Place orders easily
- Admin panel for managing items
- Responsive design (mobile friendly)

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: PHP
- Database: MySQL

## ⚙️ Installation & Setup

### 1. Clone Repository
git clone https://github.com/your-username/food-order-website.git

### 2. Move to Project Folder
cd food-order-website

### 3. Setup Local Server
- Install XAMPP / WAMP
- Move project folder to:
  htdocs (XAMPP)

### 4. Start Server
- Start Apache
- Start MySQL

### 5. Setup Database
- Open phpMyAdmin
- Create new database: `food_order`
- Import `food_order.sql` file

### 6. Run Project
http://localhost/food-order
